Retention recommendations

Set in QA Sentinels Settings. A retention value of 0 keeps that data forever.

  • events — 30 days
  • samples — 7 days
  • proc_snap — 3 days
  • inventory — 90 days

Manifest Kinds

Every ticket manifest records one of these kinds. When several views describe the same signature, one directory survives in the bucket the viability verdict requires; ties prefer correlation over crash over event over finding, then the newest manifest.

  • correlation — carries silent-stop context from preceding events.
  • crash — carries a stack; a single crash satisfies substantiation.
  • event — the weakest journal form; needs volume or another signal.
  • finding — a layer-1 heuristic finding such as hardware coverage or pstore errors; ranked after event.
